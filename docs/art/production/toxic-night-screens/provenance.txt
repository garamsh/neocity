  /tmp/w274-venv/bin/python docs/art/production/toxic-night-screens/export.py
- The script exports the title once to 1920x1080 with nearest sampling. Its logo
  is embedded in the key art. It contains no baked characters; title HUD overlays
  the unchanged #272 HD idle frames at native pixel density.
- The base is exported once, nearest, to width 1920 (height 1024), with a 56-pixel
  dark bottom pad beneath the deck. Width-preserving scale puts the generated
  walked-on floor near the existing runtime baseline; no kitchen pixels are
  painted or moved independently. Bundle capture must judge the final contact.
- Runtime destinations: art_hd/title/key_art.png and art_hd/base/kitchen.png.
  Existing import identities are retained. art_hd/manifest.json records source
  and output SHA256 digests, dimensions and processing instructions.
- Existing HD ingredient/dish icon files are reused byte-for-byte from #222;
  their original generation and source cuts remain in the environment manifest.
  HUD now loads them at 84 canvas pixels / 56 layout units. World source icons
  and their shared rendering loader are outside this task and are unchanged.

  remains in that out-of-scope folder; no common contract is changed.
