Export
- Manifest: project/levels/monster_mouth_escape/art_hd/characters/manifest.json.
  It records every output/source SHA256, crop, scale, resize dimensions,
  placement, visible bounds, canvas, baseline and pivot.
- Cells: four columns by three rows, source crops 384x341, row origins
  0, 341 and 682. Final cell is empty and unused.
- Cell order: idle, walk_1, walk_2, walk_3, walk_4, run_1, run_2, jump,
  fall, land, climb.
- Each source cell is cropped and reset with +repage, then its alpha is
  thresholded at 50 percent with ImageMagick. This discards soft transparency
  and leaves masks exactly zero or 255; RGB is not palette-quantized.
- A single shared scale per actor is derived from the idle cell's binary-alpha
  visible height: 172/source_height for chef, 108/source_height for appraiser.
  All that actor's cells use identical rounded resize dimensions and point
  sampling. No enlargement of the old runtime cuts, interpolation, raster
  warping, smoothing, rotation or pose-dependent scaling is used.
- Each resized cell is composited Over onto transparent 256x224 pixels,
  with the manifest's placement; metadata is stripped.
- Pivot [128,204] and virtual floor baseline y=204 are shared. Grounded
  silhouettes end at exclusive row 204, jump at 186 and fall at 196;
  the baseline remains 204 for every frame. Raised knees and the compressed
  landing naturally change the visible height without changing body scale.
- All face right; integration should use nearest sampling and runtime mirroring.
- Sprite pixels contain no text. Import metadata is produced by Godot import.
- Evidence strips are 2816x224: one row per actor in the cell order above,
  flat #252335 background, native pixels. Walk GIFs are 4-frame loops at
  120 ms/frame; run GIFs are 2-frame loops at 100 ms/frame, both transparent.
  These are asset previews, not captures of an integrated running game.

Limitations

- Runtime appearance, animation timing in the engine and two-player camera
  behavior are not verified by this asset-only task.
- No source code, existing art, global HD manifest, or other HD folder changed.
