Monster-mouth escape asset provenance, 2026-11-02, issue #90

Tool: Recraft, through its MCP connector, personal account. Every generation used the custom style below; Recraft ran it on model recraftv4_1_raster. No seed is exposed. Recraft returns WebP; the source URL of each generation is kept in tools/art/assets.json.
Post-processing, the same for every asset: tools/art/pixelize.py fetch decodes each WebP to PNG with ImageMagick (PNG24, or PNG32 for background-removed sources); pixelize.py process crops the rectangle given in assets.json, masks the background as given there, downscales by nearest-neighbour (the pixel at each target block's centre; a block is clear when most of it is background), snaps every opaque pixel to the 79-colour palette in assets.json (64 colours median-cut from the three concept images, plus the 15 swatches of the two character sheets), clears isolated single pixels on transparent assets, and enlarges by the asset's scale with nearest-neighbour. Per-asset crop, mask, size and scale are in assets.json.
Raw generations are not committed. Running pixelize.py fetch and process again writes the committed PNGs byte for byte.
